# 💐 Калькулятор цены букета — Telegram-бот для цветочной мастерской

Бот автоматически считает продажную цену цветка или букета так, чтобы в цену
уже были «зашиты»:

- закупка + логистика от поставщика;
- убыль/списания (скоропорт — главный скрытый убыток цветочного бизнеса);
- работа флориста (% от цены или фикс за букет);
- аренда и постоянные расходы (размазаны на плановый объём продаж);
- упаковка;
- эквайринг и комиссии маркетплейсов (Flowwow, Яндекс и т.п.);
- **НДС 5%** и **налог УСН** — режимы «Доходы 6%» и «Доходы−расходы 15%»
  переключаются в настройках;
- сверху — ваша **целевая чистая маржа**, чтобы мастерская не работала в ноль.

Стек: Python + aiogram 3, база — Supabase (PostgreSQL), код — на GitHub.

---

## 1. Создание бота в BotFather (5 минут)

1. Откройте Telegram и найдите **@BotFather** (официальный, с синей галочкой).
2. Отправьте команду `/newbot`.
3. Придумайте **имя** бота — его увидят пользователи, например:
   `Калькулятор цен моей мастерской`.
4. Придумайте **username** — должен заканчиваться на `bot`, например:
   `my_flower_price_bot`. Если занят, BotFather попросит другой.
5. BotFather пришлёт **токен** вида
   `1234567890:AAxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx`.
   ⚠️ Это пароль от бота — никому не показывайте и не коммитьте в GitHub.

## 2. Настройка Supabase (5 минут)

1. Зайдите на [supabase.com](https://supabase.com) → **Start your project** →
   войдите через GitHub.
2. **New project**: придумайте имя (например, `flower-price`), пароль от базы
   (сохраните его), регион — `Central EU` / `Frankfurt`.
3. Когда проект создастся, откройте слева **SQL Editor** → **New query**,
   вставьте всё содержимое файла [`schema.sql`](schema.sql) → **Run**.
   Создадутся таблицы `shops` и `flowers`.
4. Откройте **Project Settings → API** и скопируйте:
   - **Project URL** — в `SUPABASE_URL`;
   - ключ **`service_role`** (не `anon`!) — в `SUPABASE_KEY`.

## 3. Запуск локально

```bash
python3 -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt

cp .env.example .env             # и заполните BOT_TOKEN, SUPABASE_URL, SUPABASE_KEY

python bot.py
```

Бот запущен. Напишите ему в Telegram `/start`.

**Порядок работы:**
1. `/settings` — задайте режим УСН, % убыли, аренду в месяц, план продаж,
   оплату флориста, целевую маржу.
2. `/addflower` — наполните справочник (название + закупочная цена за стебель).
3. `/price` — соберите букет из справочника, укажите упаковку → получите
   цену с полной разбивкой и сравнением обоих режимов УСН.
4. `/quick` — быстрый расчёт по общей закупочной стоимости букета.

## 5. Круглосуточная работа (опционально)

Чтобы бот работал 24/7, разверните его на любом сервере:

- **VPS** (Timeweb, Selectel, Hetzner — от ~150 ₽/мес): те же команды,
  что и в п. 3, плюс `systemd`-юнит или `pm2` для автоперезапуска.
- **Railway / Render**: подключите GitHub-репозиторий, задайте те же
  переменные окружения в панели, стартовая команда — `python bot.py`.

## Как устроена формула

Цена `P` решается из уравнения: после вычета НДС, налога УСН, эквайринга,
комиссий и процента флориста остаток покрывает полную себестоимость `C`
и оставляет целевую маржу `m`:

- **УСН 6%:** `P = C / ( 100/105 · 0.94 − комиссии − %флориста − m )`
- **УСН 15%:** `P = 0.85·C / ( 0.85 · (100/105 − комиссии − %флориста) − m )`

Себестоимость стебля = `закупка · (1 + логистика) / (1 − убыль) + упаковка`,
плюс на каждый букет довешиваются `аренда/план продаж` и фикс флориста.

Налоги в модели (актуально на 2026 год): пониженная ставка НДС 5% для УСН
с доходом до ~272,5 млн ₽ (без права на вычет входного НДС), УСН 6%/15%.
При доходе свыше ~272,5 млн поменяйте `vat_rate` на 7 в настройках бота.
Ставки УСН в вашем регионе могут быть снижены — проверьте и задайте свои.
Это расчётный инструмент, а не налоговая консультация.

## Рынок в двух словах

Объём цветочного рынка РФ — ~450 млрд ₽ по итогам 2025 года (+12%),
прогноз на 2026 — ~500 млрд ₽. Средняя розничная наценка 100–300%
(в праздники до 350%), списания 10–30% закупки, аренда 10–25%,
зарплаты 15–25% выручки — именно поэтому дефолты бота выставлены так,
как выставлены. Подробности — в [`docs/market-overview.md`](docs/market-overview.md).
